# Content rating answers

DRAFT — NOT FOR SUBMISSION. These are the answers for the Play content-rating questionnaire. The owner still has to submit them. This file is not a certificate.

The app is a housing and flatmate discovery tool for adults. It is not directed at children.

| Question | Answer for this build |
| --- | --- |
| Violence | None. No violent content is drawn or described by the app. |
| Sexual content or nudity | None in the product UI. Users can upload a listing photo and type a chat message, so user content is not pre-screened for nudity. |
| Language | Users can type chat messages. The app does not run a profanity filter. |
| Controlled substances | None. |
| Gambling | None. No simulated gambling. |
| User-generated content | Yes. Profiles, listing text, listing photos, and chat messages are entered by users. |
| Users can interact | Yes. Likes, matches, and chat. Contact details stay hidden until that person shares them for the match. |
| Share precise location | No. There is no location permission. City and locality are typed. A visit does not store a street address. |
| Digital purchases | No. There is no checkout and no payment SDK. |
| Shares personal information publicly | A published listing shows the fields the host entered (title, city, locality, rent, deposit, furnishing, type, photos). Phone and email are not on the listing. |
| Age | Not for children. Do not opt into a program for kids. |

Expected result after the owner submits the questionnaire: a rating that reflects unrestricted user chat, not a rating that claims the app is pre-moderated. Do not guess an IARC letter here and paste it into the console as if it were returned by the questionnaire.
